# Production Readiness Assessment Site

Use this static multipage site for `0 / Assessment: Production Readiness Audit and Remediation Plan`.

The site intentionally contains production-readiness issues across:

- HTML and content structure;
- CSS and responsive behavior;
- accessibility;
- discoverability and metadata;
- performance and compatibility;
- validation, links, and release quality.

Students should audit and prioritize findings. They should not redesign or fully repair the site for Module 0.
